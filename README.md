# Botlar asosi (grammY)

Telegram botlar uchun tayyor asos (shablon). Yangi bot shu asosdan boshlanadi: obuna tekshiruvi, a'zolar va admin buyruqlari tayyor.

**Texnologiyalar:** Node.js, grammY

## Ichida nima bor
- Majburiy kanal obunasini tekshirish
- A'zolarni JSON faylda saqlash, foydalanuvchilar soni
- Barcha a'zolarga xabar yuborish va xabarni o'chirish
- Bot egasi uchun kanal va a'zolarni boshqarish

Shu asosda yasalgan botlar: [animebot](https://github.com/mjavohir06/animebot), [mahsusbot](https://github.com/mjavohir06/mahsusbot), [boburbot](https://github.com/mjavohir06/boburbot)

## Ishga tushirish

```bash
npm install
cp .env.example .env   # BOT_TOKEN= ga @BotFather bergan tokenni yozing
npm start
```
